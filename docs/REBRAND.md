# De dónde sale este proyecto

Termix **no** usa código de Termius. Este documento resume el experimento previo
de renombrar una copia local de Termius (para estudio), y por qué este cliente se
escribió desde cero.

- La app de origen es **software propietario**: se puede estudiar una copia en tu
  equipo, pero **no redistribuir** el binario ni el `.asar` renombrado.
- Herramientas del experimento: [`pilahito/termius-analisis`](https://github.com/pilahito/termius-analisis)
  (`termius-ia`, `termius-repack`, `termius-rebrand`, informe técnico).
- Lo que **sí** es publicable: un cliente propio como este, con código MIT.

Termix comparte la *idea* (SSH de escritorio con interfaz cuidada), no el código.
